Mechanism Why κtop should dominate — an a-priori prediction
The error has the signature of operator splitting; the splitting prefactor scales with the top-cell relaxation time; τtop ≈ Δz2/κtop ⇒ κtop sets the per-substrate error magnitude.
1

The error is operator splitting, not the per-substep scheme

Each Δt step: column relaxes toward equilibrium with the old Ts⁰, then SEB jumps Ts⁰ from the new T₁. The split introduces a first-order error in Δt, independent of the sub-step scheme.

Quantitative test — Δt-refinement ratios RMSE(600 s) / RMSE(60 s):

SubstrateBTCSCN
Asphalt9.49.8
Concrete roof8.29.2
Bare soil9.910.2
Smoking gun: CN is intrinsically second-order, so on its own its refinement ratio would be ~100, not ~10. The observed ~10 ratio means CN's truncation error is being dominated by a separate first-order error — the splitting.
2

The splitting error scales with τtop = Δz2/κtop

Within one Δt step, the size of the column ↔ SEB equilibrium gap depends on how fast the top cell can equilibrate compared to Δt.

Top-cell thermal response time:  τtop = Δz2 / κtop

When Δt >> τtop, the column cannot track the SEB temperature swing within one step → steep half-level gradient at the surface → large G error.

For the urban substrates at Δt = 600 s:

Substrateκtop (m2/s)τtop (s)Δt/τ
Roof7.1×10-73517×

Higher κtop → shorter τtop → larger Δt/τ at fixed Δt → bigger splitting error. Soil's slow response time keeps it nearly within one-step equilibrium even at Δt = 600 s.
3

The same κtop sets the FTCS stability bound

FTCS stability bound from von Neumann:

Δtcrit = Δz2 / (2κtop) = ½ τtop

Same parameter combination governs both failure modes:

  • FTCS: Δt > ½τ ⇒ explodes
  • BTCS / CN: Δt > τ ⇒ biased G, with bias ∝ κtop
Unifying statement: κtop is the single substrate parameter that governs both the explicit-scheme instability and the implicit-scheme inaccuracy.

Bulk admittance μeff = √(λeffCeff) modulates the amplitude of the surface temperature swing but not the column's response time — expect it as a secondary control. Layer-interface descriptors should be third-tier.

Testable a-priori prediction (the bridge to the next slide): if this mechanism is right, then in any ensemble of urban substrates the top predictor of BTCS coarse-Δt RMSE should be κtop, with μeff as a clear second and layer-structure descriptors as a distant third. → Figure 6 puts this prediction to the test on a 150-column synthetic ensemble.
